What happens next

  1. Connect over SSH and pin the host key.
  2. Check architecture, memory, disk, cgroups and clock sync.
  3. Install Docker Engine and write a hardened daemon.json.
  4. Open the swarm ports (2377/tcp, 7946/tcp+udp, 4789/udp).
  5. Join the cluster using a freshly fetched join token.
  6. Apply node labels and mark the node ready.

The SSH user needs passwordless sudo. Waggle never stores passwords.
